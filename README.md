# GYMLOG

GYMLOG は、Android 向けのシンプルな筋トレ記録アプリです。

トレーニング中に重量・回数を手早く記録でき、履歴や前回の内容を確認しながら次のセットを組み立てられます。記録は端末内に保存され、オフラインでも利用できます。

## 主な機能

- 重量・回数をセットごとに記録
- kg / lbs の切り替え
- セットの追加・削除
- 前回の重量・回数を確認・コピー
- 前回のトレーニングメニューをコピー
- レストタイマー
- 日付別のトレーニング履歴
- 履歴の検索・詳細表示
- 種目別の履歴表示
- 部位別の種目ライブラリ
- オリジナル種目の追加・編集
- シートの高さなどの種目共通メモを記録画面で確認・編集
- トレーニングメニューの保存・呼び出し
- JSON形式でのバックアップ・復元
- オフライン動作

レストタイマーは下部ナビゲーションの上に表示され、どの画面からでも操作できます。「秒数を変更」を開くと時間を設定できます。

## データについて

トレーニング記録は端末内に保存されます。GYMLOG がトレーニング記録を外部サーバーへ送信することはありません。

アプリのデータを消去した場合や、アプリをアンインストールした場合には記録が失われる可能性があります。機種変更や再インストールに備えて、アプリ内のバックアップ機能から定期的に JSON ファイルを保存することをおすすめします。

## 使い方

1. 「記録」で日付と種目を選び、重量・回数を入力して「記録を保存」を押します。
2. シートの高さなどは各種目の「種目共通メモ」に入力します。次回以降も同じメモを参照できます。
3. 「履歴」の「種目別」を選ぶと、種目ごとの重量・回数を日付順に確認できます。
4. レストタイマーの「開始」を押すとカウントダウンします。「秒数を変更」で時間を設定できます。

## アップデート

既に GYMLOG を使っている場合は、アンインストールせずに新しい APK を開いて更新してください。更新前に「設定」からバックアップを保存しておくことをおすすめします。
