# IRONLOG

スマートフォンのブラウザで使える、オフライン対応の筋トレ記録アプリです。

## 主な機能
- セットごとの重量・回数、kg/lbs切り替え
- セット追加・削除、前回の種目記録のコピー
- レストタイマー（30/60/90/120秒・自由入力）
- 日付別の記録、履歴検索・詳細表示
- 部位別の種目ライブラリ（追加・編集）
- トレーニングメニューの保存・呼び出し
- JSONバックアップ・復元
- ダークテーマ、ホーム画面への追加、オフライン利用

## 公開
GitHub Pages は GitHub Actions で配信します。ワークフローが初回実行されるまで数分かかることがあります。**Settings → Pages → Build and deployment → Source** が **GitHub Actions** になっていることも確認してください。

公開URL: https://wassanborn72.github.io/training-log/

## データとプライバシー
トレーニング記録はブラウザの localStorage に保存され、サーバーには送信されません。ブラウザデータの消去、プライベートブラウズ、端末変更などで消える可能性があるため、定期的にJSONバックアップを保存してください。

## オフラインについて
初回アクセス時はオンライン接続が必要です。Service Worker がファイルをキャッシュした後は、同じブラウザからオフラインでも起動できます。ホーム画面への追加はブラウザのメニューから行ってください。スマートフォンOSによってはバックグラウンド中のタイマー動作が制限されます。
